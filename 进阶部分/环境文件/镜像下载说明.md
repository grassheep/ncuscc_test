# Ubuntu 镜像下载说明

虚拟机用的系统镜像 `ubuntu-24.04.3-live-server-amd64.iso`（3.3 GB）**没有放进仓库**，原因和替代办法都在这一页。

---

## 一、为什么不在仓库里

这个文件放不进 GitHub，三条路都走不通：

| 方式 | 上限 | 3.3 GB 能否通过 |
| --- | --- | --- |
| 普通 Git 提交 | 单文件 **100 MB** | ❌ |
| Git LFS | 单文件 **2 GB**，免费额度 1 GB 存储 | ❌ 两处都超 |
| Releases 附件 | 单文件 **2 GiB** | ❌ |
| 分卷压缩后传 Releases | 每卷 < 2 GiB | 理论可行，但要切两块、下载后手动合并，得不偿失 |

而且这本来就是个**标准官方镜像**，任何人都能从 Ubuntu 官网原样下载，校验值也一样。为了省一次 5 分钟的下载，往仓库里塞 3.3 GB，对复现者并没有帮助。

---

## 二、下载地址

### 官方源

```text
https://releases.ubuntu.com/24.04/ubuntu-24.04.3-live-server-amd64.iso
```

同目录下的 `SHA256SUMS` 是官方校验文件：

```text
https://releases.ubuntu.com/24.04/SHA256SUMS
```

### 国内镜像（速度更快，内容完全相同）

```text
https://mirrors.tuna.tsinghua.edu.cn/ubuntu-releases/24.04/ubuntu-24.04.3-live-server-amd64.iso
https://mirrors.ustc.edu.cn/ubuntu-releases/24.04/ubuntu-24.04.3-live-server-amd64.iso
```

> 以上地址在 2026-10-18 实测可访问（清华 TUNA、中科大均返回 HTTP 200；阿里云镜像会 302 跳转，用浏览器打开同样可以下载）。

## 三、校验值

```text
c3514bf0056180d09376462a7a1b4f213c1d6e8ea67fae5c25099c6fd3d8274b
```

这个值与两处一致：

1、Ubuntu 官方 `SHA256SUMS` 里 `ubuntu-24.04.3-live-server-amd64.iso` 那一行；

2、对开发机上的那份镜像实际执行 `sha256sum` 的结果（3,303,444,480 字节）。

**两者逐字相同，说明开发时用的就是未经改动的官方镜像。**

### 怎么校验

Linux / macOS：

```bash
sha256sum ubuntu-24.04.3-live-server-amd64.iso          # Linux
shasum -a 256 ubuntu-24.04.3-live-server-amd64.iso     # macOS
```

Windows（PowerShell）：

```powershell
Get-FileHash .\ubuntu-24.04.3-live-server-amd64.iso -Algorithm SHA256
```

输出与上面那串 64 位十六进制一致即可。

> 顺带说明：`24.04.4` 和 `24.04.5` 的镜像也能装，后续步骤完全一样。装完随便 `apt upgrade` 一下，系统版本号自然会到 24.04.x。**只有一点要注意**——不同点版本的镜像，校验值不同，别拿错行去比对。

## 四、拿到镜像之后

1、VMware Workstation → 新建虚拟机 → 安装程序光盘映像文件 → 选这个 ISO；

2、客户机选 Ubuntu 64 位，**磁盘先给 20 GB**（默认安装只会给 `/` 分到 9.8 GB，装 CUDA 会不够，后面必须扩容）；

3、安装时用默认设置，勾上 OpenSSH server 会更方便；

4、装完第一件事是**扩容**，不是装 CUDA —— 顺序反了会连锁报错。

完整的搭建步骤（扩容的 `lvextend`、装哪三个包、`-allow-unsupported-compiler` 为什么必须加、无卡时怎么判读输出）见仓库根目录的：

```text
进阶部分/环境文件/环境配置（AI生成）.md
```

其中：

- **4.4 节**：LVM 扩容（`/` 从 9.8 G → 18 G）
- **4.5 节**：装 `build-essential` + `nvidia-cuda-toolkit` + `nvidia-cuda-dev`
- **4.6 节**：三条编译验证命令
- **第 1 章**：十秒判断这台机器有没有显卡（决定走哪条路线）
